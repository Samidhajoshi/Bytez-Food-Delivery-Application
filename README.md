# 🍔 Bytez – Food Delivery Application

This is an ongoing **full-stack food delivery web application** built using the **MERN stack** with integrated online payments.

---

## 🚀 Tech Stack

- **Frontend:** React  
- **Backend:** Node.js + Express.js  
- **Database:** MongoDB  
- **Payment Gateway:** Stripe  

---

## 🏗️ Architecture
React (Frontend)

Node.js + Express (Backend API)

MongoDB (Database)

Stripe (Payments)

---

## ✨ Features

- 🛒 Browse food items  
- 📦 Add to cart & manage orders  
- 💳 Secure online payments using Stripe  
- 🔐 User authentication   
- 📱 Responsive UI
